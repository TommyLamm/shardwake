# M5-01 等級與技能樹

- 里程碑：M5 成長、終局與上架
- 前置：M4 完成
- 狀態：未開始

## 目標

讓每次任務都帶來長期成長感，而且技能能明顯改變打法，特別是移動流派。

## 設計

- 等級 1–30（之後可擴充）；經驗來源：擊殺、完成目標、完成任務；曲線可調。
- 每升一級得到 1 個技能點；三條技能樹，各約 12 個節點：
  - 疾行：Dash 充能 +1、跑牆時間、抓鉤冷卻、滑鏟推進、空中機動、速度越快護盾回復越快⋯⋯
  - 槍械：換彈速度、爆頭傷害、彈匣、穩定、切槍速度、各武器類型專精⋯⋯
  - 科技：護盾容量、元素效果、手雷（M5-02）、超載充能⋯⋯
- 每條樹有 1 個會改變玩法的終極節點。
- 花晶幣可以重置技能。
- 所有效果都經過 StatAggregator（M2-06）計算。

## 任務

- [ ] 經驗與等級曲線資料表；升級演出（音效、HUD 提示）。
- [ ] 技能樹資料（節點、前置條件、效果）與 hook 實作（沿用 M2-02 的詞綴 hook）。
- [ ] 技能樹介面：可縮放、可拖曳的樹狀圖，顯示節點說明與數值變化。
- [ ] 存檔新增等級、經驗、技能配置（在 M2-04 的框架內加遷移）。
- [ ] 平衡表：各等級的預估擊殺時間與存活時間。

## 交付（給後續計畫）

- 等級與技能系統（M5-02 的手雷與超載、M5-03 的難度解鎖使用）。

## 驗收

- [ ] 測試：技能效果即時反映在最終數值；重置後數值完全回到「基礎＋裝備」。
- [ ] 實機：三條技能樹各點一半後，打法差異明顯（記錄試玩心得）。
