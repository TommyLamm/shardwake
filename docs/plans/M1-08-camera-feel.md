# M1-08 鏡頭手感

- 里程碑：M1 手感原型
- 前置：M1-05（可與 M1-06、M1-07 並行）
- 狀態：未開始

## 目標

讓速度、衝擊與姿態看得出來、感覺得到，但不會暈；每個效果都能個別關閉。

## 範圍

- 包含：CameraRig、FOV、傾斜、落地彈簧、頭部晃動、創傷式震動、速度線，以及對應設定。
- 不含：viewmodel 動畫（M1-11）、後座力（M1-10）。

## 任務

- [ ] `camera/CameraRig.ts`：每個渲染畫面以插值後的位置加上眼高彈簧（蹲、滑鏟、攀爬時平滑）定位相機；所有效果疊加成偏移，與遊戲邏輯分離，不改變命中判定用的視線方向（後座力除外）。
- [ ] FOV：設定值是水平 FOV（預設 103°，範圍 80–120），依畫面比例換算成垂直 FOV。動態 FOV = 基礎值 ＋ 速度對應（10→22 m/s 對應 +0→+8°）＋ Dash 衝擊（+10°，0.3 s 回落）＋ 抓鉤中 +4°；以 `damp` 平滑；設定可關閉動態 FOV。
- [ ] 傾斜（roll）：跑牆 12°（朝牆外）、滑鏟 3°、側移 1°、側向 Dash 2°，用彈簧平滑；設定可調強度。
- [ ] 落地：依 `land.impactSpeed` 產生下沉衝量（最大 0.12 m）並輕微往下點頭，彈簧回彈（頻率 8 Hz、阻尼 0.7）。
- [ ] 頭部晃動：依移動速度與腳步節奏的小幅垂直／水平擺動（衝刺時 ±0.015 m），空中停止；設定可關閉。
- [ ] 創傷式震動：`addTrauma(amount)`，位移與旋轉 = trauma² × 雜訊，每秒衰減；設定可調強度 0–100%。來源：開火、爆炸（依距離）、重落地、受擊。
- [ ] 速度線（`fx/SpeedLines.ts`）：水平速度 > 14 m/s 時淡入的螢幕空間速度線（後處理 Effect 或全螢幕四邊形）；設定可關閉。
- [ ] 調參面板「鏡頭」資料夾。

## 交付（給後續計畫）

- `CameraRig.addTrauma()`、`addFovKick()`、`addRollImpulse()`，給武器、爆炸、受擊使用。
- 目前的水平／垂直 FOV（準星大小與開鏡靈敏度換算會用到）。

## 驗收

- [ ] 測試：水平↔垂直 FOV 換算正確（16:9、21:9、4:3）；彈簧在 30–240 Hz 畫面下行為一致。
- [ ] 所有效果關閉時，鏡頭完全穩定（給容易暈的玩家）。
- [ ] 實機：跑牆傾斜、Dash 衝擊、落地下沉都明顯但不暈；記錄最終預設值。
