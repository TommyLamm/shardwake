# M1-12 靶標、玩家受擊與戰鬥回饋

- 里程碑：M1 手感原型
- 前置：M1-10（建議先完成 M1-11）
- 狀態：未開始

## 目標

讓每一次命中、爆頭、擊殺、受擊都有清楚的回饋，並提供會反擊的靶標來測試閃避手感。

## 範圍

- 包含：傷害介面與命中區、三種靶標、DPS 計、玩家護盾與生命、命中標記、傷害數字、受擊方向指示。
- 不含：真正的敵人 AI（M3）、元素與防禦層（M2-02）。

## 任務

- [ ] `combat/Damage.ts`：`Damageable` 介面（`applyDamage(info)`）；命中區 `hitZone: 'body' | 'crit'` 由 collider 標記；傷害計算管線（基礎 → 距離衰減 → 爆頭倍率 → 之後 M2-02 加入詞綴與元素）。
- [ ] 靶標（`combat/targets/`）：
  - 靜態假人：身體加頭部弱點；1000 HP，2.5 s 未受傷就回滿；被「擊殺」時倒下，1.5 s 後重置；命中時閃白。
  - 移動靶：在軌道上左右移動（3–8 m/s，隨機變向）。
  - 訓練無人機：在戰區內以 12–25 m 半徑繞著玩家飛，偶爾換高度；每 1.5 s 發射慢速能量球（18 m/s、拖尾明顯，可用 Dash 閃避）；150 HP、核心是弱點；擊毀時爆炸，5 s 後重生；進入戰區才啟動，可在選單與調參面板關閉。
- [ ] DPS 計：靶場看板顯示最近 5 s 的滾動 DPS、總傷害、爆頭率。
- [ ] 玩家生命：護盾 100（3 s 未受傷後以每秒 40 回復）、生命 100（原型中慢速回復）；死亡 → 0.8 s 淡出 → 在出生點重生；事件 `playerDamaged { amount, dir, shieldBroken }`、`playerDied`。
- [ ] 命中回饋（`ui/`）：
  - 命中標記：一般（白色 X）、爆頭（黃色、較大）、擊殺（紅色、短暫放大並輕微震動）。
  - 浮動傷害數字：DOM 物件池（上限 48），從命中點投影到螢幕後往上飄散；爆頭是黃色並放大；同一目標短時間內的數字可以合併累加（設定可切換）。
  - 受擊方向指示：螢幕邊緣依攻擊來源方向出現紅色弧形；護盾破裂時出現藍色碎裂邊框；低生命時出現紅色暗角。
- [ ] 調參面板：設定靶標血量、無人機開關與數量、無敵模式。

## 交付（給後續計畫）

- `Damageable`、命中區標記方式、傷害計算管線（M2-02 擴充，M3 的敵人實作）。
- 玩家 `Health`（護盾／生命）與受擊事件。
- 傷害數字與命中標記元件（M2-02 會加入元素與防禦層的顏色）。

## 驗收

- [ ] 測試：爆頭倍率、距離衰減、範圍傷害計算正確；DPS 計的數值與注入的傷害序列一致。
- [ ] 實機：靶場上每把武器的實測 DPS 與預估值相近（記錄表格）；無人機的能量球可以用 Dash、滑鏟、跑牆閃避。
- [ ] 受擊方向指示正確：從左邊被打時，指示出現在左邊。
