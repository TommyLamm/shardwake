# M1-14 HUD、選單與設定

- 里程碑：M1 手感原型
- 前置：M1-07、M1-12
- 狀態：未開始

## 目標

完成繁體中文的 HUD、開始畫面、暫停選單、設定與按鍵配置；開始、遊玩、結束、重新開始都能在平台 iframe 內完成。

## 範圍

- 包含：i18n、HUD 版面、開始畫面、暫停選單、設定頁、按鍵配置、全螢幕按鈕規則、iframe 顯示模式驗證。
- 不含：背包介面（M2-05）、任務介面（M4）。

## 任務

- [ ] `i18n/zh-TW.ts`：所有介面字串集中管理，提供 `t(key, params)`；之後可以加其他語系。
- [ ] HUD（DOM + CSS，`ui/HUD.ts`）：
  - 中央：準星、命中標記、「可勾取」提示。
  - 左下：護盾／生命條（含受擊延遲條）、Dash 充能格、噴射燃料條、抓鉤冷卻環。
  - 右下：武器名、彈匣／備彈、射擊模式。
  - 上方：計時器（跑酷用）、提示訊息佇列。
  - HUD 只讀取狀態與事件，不持有遊戲邏輯；依 iframe 短邊縮放，1280 × 720 到 3440 × 1440 都清楚；只在數值改變時更新 DOM。
- [ ] 開始畫面：遊戲名稱、「點擊開始」（同時鎖定滑鼠並啟用音效）、設定、操作說明。
- [ ] 暫停選單（Esc 或失去滑鼠鎖定時）：繼續、設定、按鍵配置、重置位置、重新開始訓練、返回標題。平台全螢幕下短按 Esc 會送到遊戲；Pointer Lock 的退出由瀏覽器處理。兩種情況都要正確進入暫停，而且不會重複切換。
- [ ] 設定頁籤：
  - 控制：靈敏度（Source 尺度，附 DPI 欄位與 cm/360 顯示）、開鏡靈敏度倍率、Y 軸反轉、自動衝刺、蹲／開鏡／抓鉤用按住或切換。
  - 畫面：FOV（水平）、畫質預設、渲染比例、陰影、Bloom、顯示 FPS。
  - 鏡頭：震動強度、頭部晃動、動態 FOV、速度線、鏡頭傾斜強度。
  - 音效：主音量、音效、介面（音樂在 M5-06 加入）。
  - 「恢復預設」；設定即時套用並存檔；儲存不可用時顯示提示，但照常運作。
- [ ] 按鍵配置頁：每個動作兩欄綁定、點擊後按下新的鍵或滑鼠鍵、衝突提示、拒絕保留鍵、Ctrl 警告、恢復預設。
- [ ] 全螢幕按鈕：只在沒有嵌入 iframe 時顯示，由玩家點擊觸發；嵌入平台時交給平台的全螢幕。
- [ ] 視覺：未來科技風格（細線框、斜角、青色主色、等寬數字）；動畫只用 CSS transform／opacity，避免版面重排。
