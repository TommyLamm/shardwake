# M2-03 掉落、拾取與彈藥

- 里程碑：M2 刷寶核心
- 前置：M2-01
- 狀態：未開始

## 目標

讓「看到掉落 → 走過去 → 拿起來比較」這個循環順暢又有期待感，並加入有節奏感的彈藥經濟。

## 設計

- 掉落表：依來源（一般敵人、精英、Boss、寶箱）、等級、難度決定掉落數量與稀有度權重；保底機制（連續 N 次沒有史詩以上時提高機率）。
- 地面物品：程序槍模、稀有度色光柱（稀有度越高，光柱越高越亮，並有專屬音效）、輕微物理彈跳後靜止；設定可隱藏低稀有度光柱。
- 拾取：看向物品時顯示物品卡（含與目前裝備的比較）；按 E 拾取到背包，長按 E 直接裝備替換；彈藥、晶幣、修復球自動吸附拾取。
- 彈藥：三種備彈池——普通（突擊步槍、衝鋒槍、手炮、連發步槍）、特殊（霰彈槍、狙擊槍）、重型（發射器、機槍）；上限與掉落量依消耗平衡；過熱武器不需要彈藥。M1 的無限備彈改為設定項，訓練場仍然無限。
