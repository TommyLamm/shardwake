# M2-02 詞綴、元素與狀態效果

- 里程碑：M2 刷寶核心
- 前置：M2-01
- 狀態：未開始

## 目標

讓詞綴真正改變玩法，特別是和移動結合的「機動系」詞綴；加入元素、狀態效果與敵人防禦層。

## 設計

- 詞綴 hook：`onFire`、`onHit`、`onCrit`、`onKill`、`onReload`、`onMagEmpty`、`onSlide`、`onDash`、`onWallRun`、`onGrappleRelease`，以及持續性的 `modifyStats(ctx)`（依是否在空中、目前速度、生命比例等）。
- 詞綴分類：
  - 數值：傷害 +%、爆頭傷害 +%、彈匣 +%、換彈速度、穩定、操控、射程。
  - 元素（附加元素傷害與狀態）：

    | 元素 | 對防禦層 | 狀態效果 |
    | --- | --- | --- |
    | 電弧 | 護盾 ×2 | 連鎖跳到附近的敵人 |
    | 熱能 | 機體 ×1.5 | 燃燒持續傷害 |
    | 腐蝕 | 裝甲 ×2 | 持續傷害並降低裝甲 |
    | 冷凍 | — | 累積緩速，滿了就凍結；凍結時爆頭 ×1.5 |

  - 行為：每 N 發爆裂彈、跳彈、穿透 +1、過載（持續開火時射速遞增）、機率不耗彈、擊殺回填彈匣、爆頭回盾、弱點標記、追蹤彈（發射器）。
  - **機動系（本作特色）**：
    - 動能轉換：傷害隨移動速度提升，最高 +30%
    - 空中射手：空中時散布 −50%、傷害 +15%
    - 滑鏟裝填：滑鏟時補回 30% 彈匣
    - 衝刺充能：Dash 後 3 s 內射速 +25%
    - 鉤擊：脫鉤後 2 s 內爆頭傷害 +40%
    - 跑牆專注：跑牆時開鏡瞬間完成、後座 −50%
    - 落地震波：從高處落地時造成範圍傷害
  - 詞綴分 T1–T3 等級並有互斥群組；傳說詞綴是更強、會改變玩法的版本；原型武器有專屬詞綴。
- 敵人防禦層（為 M3 準備）：護盾（藍）、裝甲（黃）、機體（白）。傷害數字的顏色依防禦層與元素區分。
