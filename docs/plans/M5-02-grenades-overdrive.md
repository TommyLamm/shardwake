# M5-02 手雷與超載技能

- 里程碑：M5 成長、終局與上架
- 前置：M5-01
- 狀態：未開始

## 目標

加入手雷與大招，讓戰鬥有更多爆發時刻與戰術選擇。

## 設計

- 手雷（G）：裝備的「手雷模組」決定類型——碎裂、電弧、冷凍、奇點（把敵人吸在一起）、黏性；冷卻制或充能制；按住時顯示拋物線預覽，放開投擲。
- 超載（X）：造成傷害時累積充能；裝備三種「超載核心」之一：
  - 時間緩流：周圍時間變成 0.3 倍、自己維持正常速度，持續 4 s。
  - 武器超頻：無限彈藥、射速 +50%，持續 8 s。
  - 軌道打擊：標記區域，延遲轟炸。
- 按鍵都可以重新綁定；HUD 顯示手雷充能與超載量表。

## 任務

- [ ] 手雷系統（投擲物理、預覽、引爆、元素效果）與手雷模組生成。
- [ ] 超載系統、三種核心、演出（後處理、音效、鏡頭）。
- [ ] HUD 元件與按鍵綁定。
- [ ] 平衡：充能速度與傷害。

## 交付（給後續計畫）

- 手雷與超載框架（M5-03 的製作、M5-04 的新內容可以新增類型）。

## 驗收

- [ ] 實機：每種手雷與超載核心效果明顯、時機好掌握；時間緩流不影響輸入延遲與物理穩定。
