## 目標

把原型打磨到可以交付：效能達標、手感預設值定案、錯誤處理完整、說明文件與封面就緒。

## 任務

- [ ] 效能剖析：用 Chrome Performance 錄 30 s 的激烈戰鬥加高速移動，找出長任務、GC 與過多的 draw call。目標：高畫質 1080p、GTX 1650 ≥ 120 FPS，frame time 第 99 百分位 < 12 ms；熱迴圈零配置（Memory 面板看不到鋸齒狀 GC）。
- [ ] 最佳化：合併與 instancing、特效數量上限、HUD 更新節流、陰影相機範圍、各畫質的預設渲染比例。
- [ ] 手感總調校：依實機試玩調整 MovementConfig、鏡頭參數與 5 把武器的預設值；把定案值寫回原始碼的預設，並在「實作紀錄」留下調校紀錄（改了什麼、為什麼）。
- [ ] 錯誤處理：WebGL 不可用或 context lost 時，顯示中文錯誤畫面與重試按鈕；Rapier 初始化失敗時有提示；任何 `await` 失敗都不會變成白畫面。
- [ ] `#cover` 封面模式：固定在訓練場最好看的角度、隱藏 HUD、以 800 × 500 渲染，並提供「下載封面」按鈕（只在 `#cover` 出現）；產生正式的 `public/cover.png`（≤ 5 MiB）。
- [ ] `public/game.json`：完善 `description`、`instructions`（操作說明）、`tags`（≤ 8 個，每個 ≤ 24 字元）。
- [ ] `README.md`：遊戲簡介、操作表、開發指令、調參面板與錄製重播的用法、試玩清單（各移動技、各武器、無人機閃避、調整並匯出預設）、已知問題。
- [ ] 全面驗證：`npm run typecheck && npm test && npm run build && npm run check:dist`；在 Chrome、Edge 與平台模擬頁實測。
