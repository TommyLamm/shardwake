# M4-03 任務地圖生成器

- 里程碑：M4 基地與程序任務
- 前置：M4-02
- 狀態：未開始

## 目標

用種子產生每次都不同、但一定能通關、長度適中的任務地圖。

## 設計

- 種子化生成：主線路徑（入口 → 3–6 個戰鬥區 → Boss 前廳 → Boss），加上 0–3 條支線（寶物房、精英房）；任務長度 8–15 分鐘。
- 擺放：連接點配對（方向相反、尺寸相容）、OBB 重疊檢查、失敗時回溯；限制高度變化。
- 驗證：入口到 Boss 可達（導航連通，加上移動能力的假設）；未使用的連接點用封牆模組封閉。
- 內容填入：依房間預算放遭遇戰、寶箱、可破壞物；加入需要抓鉤或跑牆才到得了的隱藏區，獎勵比較好。
- 生成在載入畫面中完成（目標 < 1 s）；相同種子完全重現，並顯示種子供分享。

## 任務

- [ ] `missions/generator/`：路徑圖、擺放、回溯、封牆。
- [ ] 驗證器與內容填入。
- [ ] 除錯視圖：俯瞰圖、房間編號、路徑。
- [ ] 測試。

## 交付（給後續計畫）

- `generateMission(seed, params)` → 可載入的 Level（M4-04 使用）。

## 驗收

- [ ] 測試：1000 個種子全部生成成功、沒有重疊、都可達；相同種子輸出相同。
- [ ] 生成時間 < 1 s（記錄實測值）。
