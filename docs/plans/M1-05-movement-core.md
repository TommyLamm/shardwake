# M1-05 移動 I：地面、空中、跳躍、蹲、滑鏟 ★

- 里程碑：M1 手感原型
- 前置：M1-03、M1-04
- 狀態：未開始
- 檢查點：★ 完成後可以在灰盒場地試玩基本移動

## 目標

建立玩家控制器骨架與基礎移動。手感要做到：放開就停、起步即達速、跳躍俐落、滑鏟有爆發力。

## 範圍

- 包含：MovementConfig、PlayerController 與狀態機、地面／空中／跳躍／蹲／滑鏟、重生、調參面板綁定、無頭測試。
- 不含：跑牆與攀爬（M1-06）、二段跳／噴射／Dash／抓鉤（M1-07）、鏡頭效果（M1-08）。

## 任務

- [ ] `player/MovementConfig.ts`：所有移動參數、預設值與說明文字（給調參面板）；之後的計畫在同一個檔案擴充。
- [ ] `player/PlayerController.ts`：
  - 膠囊體：站姿高 1.8 m、蹲姿 1.0 m、半徑 0.35 m；眼高 1.65／0.95 m。
  - Rapier `KinematicCharacterController`：offset 0.01、autostep 0.35 m、snapToGround 0.3 m、最大爬坡 50°、最小下滑坡 55°。
  - 速度自己維護：每步算期望位移 → `computeColliderMovement` → 依實際碰撞法線把速度投影（撞牆不累積速度、沿牆滑行）。
  - 地面探測：向下 shape cast，取得地面法線與表面材質（坡度加速與腳步聲用）。
  - 狀態機：`Ground`、`Air`、`Slide`（後續計畫再加 `WallRun`、`Mantle`、`Dash`、`Grapple`）；每個狀態有 `enter / step / exit`，轉換規則集中管理；**切換狀態永不硬性歸零速度**。
  - 輸出 `PlayerState`（位置、上一步位置〔插值用〕、速度、狀態、是否著地、眼高），以及事件 `jump`、`land { impactSpeed }`、`slideStart`、`slideEnd`、`crouch`、`footstep { surface }`、`respawn`。
- [ ] 地面移動（Source 式 `accelerate(wishDir, wishSpeed, accel)` ＋ `friction(stopSpeed, friction)`）：
  - 跑 7.5 m/s；**自動衝刺**：輸入方向在正前方 ±50° 內時 10.5 m/s，開火或開鏡時降回跑速；設定可關閉，改用手動衝刺鍵。
  - 蹲走 3.5 m/s；加速 12、摩擦 6、stopSpeed 2。
  - 落地後 1 步內不套摩擦，保留連跳動量（可調）。
- [ ] 跳躍：高度 1.3 m（由高度與重力反推初速）、重力 24 m/s²；土狼時間 0.12 s；跳躍緩衝 0.15 s（用 M1-03 的 `InputBuffer`）；在斜坡上沿地面法線與正上方混合的方向起跳（比例可調）。
- [ ] 空中：Quake 式 air strafe（空中加速 2.5、wishSpeed 上限 1.2 m/s）＋ air control（每秒把水平速度往輸入方向旋轉若干度，不增速）；水平速度超過 22 m/s 時，對超出部分施加 2 /s 阻力。
- [ ] 蹲下：按住或切換（設定）；膠囊高度 0.12 s 平滑過渡；起身前用 `overlap` 檢查頭頂空間，不夠就維持蹲姿。
- [ ] 滑鏟：
  - 進入：在地面、速度 ≥ 7 m/s 時按蹲；空中按住蹲、落地時速度足夠也直接接滑鏟。
  - 推進 +3.5 m/s，推進冷卻 1.2 s（冷卻中只滑不加速）；摩擦 0.8；坡度加速 = 重力沿坡面分量 × 1.0；轉向速率 90°/s。
  - 結束：速度 < 4.5 m/s，或在按住模式下放開蹲；滑鏟中跳躍保留水平動量。
- [ ] 重生：碰到 `killVolume` 回到最近檢查點，速度歸零並發出 `respawn`。
- [ ] 相機暫時直接放在插值後的眼高位置，加上 M1-03 的 yaw／pitch；正式鏡頭效果在 M1-08。
- [ ] 調參面板「移動」資料夾：綁定所有參數；監看速度曲線圖、目前狀態、是否著地、地面法線。

## 驗收

`tests/movement.test.ts`（Rapier 無頭世界＋腳本輸入）：

- [ ] 平地起步 0.15 s 內達到跑速的 95% 以上；放開後 0.35 s 內停止。
- [ ] 跳躍最高點約 1.3 m（±3%）；離開平台 0.1 s 內按跳可以起跳，0.2 s 後不行；落地前 0.12 s 按跳，會在落地瞬間起跳。
- [ ] 滑鏟進入時有推進，冷卻中的第二次滑鏟沒有推進；15° 下坡滑鏟會加速。
- [ ] 在矮洞下放開蹲，不會起身卡進天花板。
- [ ] 斜向撞牆會沿牆滑行，不黏牆、不抖動。

實機：

- [ ] 在訓練場跑、跳、滑鏟、連跳都流暢；在「實作紀錄」寫下主觀手感與調整過的數值。
