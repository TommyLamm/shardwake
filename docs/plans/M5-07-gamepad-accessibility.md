# M5-07 手把與無障礙

- 里程碑：M5 成長、終局與上架
- 前置：M1 完成（越晚做，要接的介面越多；建議在 M5-08 之前完成）
- 狀態：未開始

## 目標

讓手把玩家也能流暢遊玩，並讓更多玩家能舒服地玩這款遊戲。

## 設計

- 手把（平台 iframe 允許 gamepad）：Gamepad API、預設配置、靈敏度與反應曲線、死區、瞄準輔助（減速＋輕微吸附，可關閉）、支援時加入震動、所有介面都能用手把操作。
- 無障礙：
  - 稀有度除了顏色還有形狀標記；色盲模式（調整重要顏色）。
  - 「舒適」預設：關閉閃光、降低震動與動態效果。
  - 字體大小、HUD 縮放。
  - 所有按住動作都可以改成切換；提供單手配置預設。
- `devices` 仍然只標 `desktop`：支援手把不等於支援手機觸控。
