# M1-11 武器表現：Viewmodel、特效、準星 ★

- 里程碑：M1 手感原型
- 前置：M1-09、M1-10
- 狀態：未開始
- 檢查點：★ 完成後可以試玩射擊手感

## 目標

讓 5 把武器看起來、動起來都有份量且各有特色，並讓準星精確反映實際散布。

## 範圍

- 包含：viewmodel 渲染、程序槍模、viewmodel 動畫、狙擊鏡、射擊特效、動態準星、預熱。
- 不含：命中標記與傷害數字（M1-12）、音效（M1-13）。

## 任務

- [ ] Viewmodel 渲染：獨立的 `vmScene` 與 `vmCamera`（固定 FOV 60°）；在 PostFX 中，世界 RenderPass 之後加第二個 RenderPass，只清深度、不清顏色；viewmodel 也套用 Bloom，而且不會穿牆。
- [ ] `weapons/WeaponModelFactory.ts`：依 `WeaponDef.model` 組裝程序槍模——機匣、槍管（長度／粗細）、護木、彈匣（可拆，換彈動畫用）、瞄具（機瞄／紅點／狙擊鏡）、槍托、發光條（顏色之後對應稀有度）；共用材質、合併靜態部件；預留 `manufacturer` 參數（M2-01 每家廠商一套部件風格）。
- [ ] `weapons/Viewmodel.ts` 動畫（全部用彈簧，與畫面更新率無關）：
  - 擺動（滑鼠位移的反向延遲，有上限）、移動晃動（8 字形，隨速度變化）、衝刺姿勢（下壓並側轉）、滑鏟傾斜 15°、跑牆時往牆外偏、空中微抬、落地彈跳。
  - 開鏡：依開鏡進度，把瞄具對齊畫面中心（每把武器有自己的 `adsOffset`）。
  - 後座踢動：位置後推、槍口上仰；每把武器的彈簧參數不同。
  - 換彈：程序關鍵影格（槍身傾斜 → 彈匣拔出掉落 → 新彈匣插入 → 上膛），時間軸依 `reload*` 縮放；霰彈逐發插彈。
  - 切槍：下放／舉起；近戰：前刺。
- [ ] 狙擊鏡：開鏡完成時顯示瞄準鏡遮罩與縮放後的世界 FOV，並隱藏 viewmodel。
- [ ] 特效（全部物件池化，放在 `fx/`）：
  - 槍口火光：加法混合 sprite（隨機旋轉、縮放）＋**預先建立的固定點光源**，只調整亮度。
  - 曳光：從槍口到命中點的拉長發光四邊形，快速淡出；霰彈每顆彈丸一條（可降量）。
  - 命中火花：InstancedMesh 粒子，依表面法線噴出；打到發光材質時換顏色。
  - 彈孔貼花：貼在表面（polygonOffset），上限 96，循環覆蓋。
  - 電漿投射物：發光球加拖尾；爆炸：擴散球殼、閃光、震動。
  - （可選）彈殼拋出：拋物線加地面彈跳，上限 32。
- [ ] `ui/Crosshair.ts`：依武器類型使用不同樣式（十字／圓／點）；半徑 = `tan(spread) / tan(vFov / 2) × (畫面高度 / 2)`，精確反映實際散布；開鏡時縮小，狙擊開鏡時淡出。
- [ ] 預熱：viewmodel 與所有特效材質加入 `registerWarmup()`。

## 交付（給後續計畫）

- `WeaponModelFactory`（之後依廠商與稀有度換部件與顏色）。
- 特效池 API：`spawnImpact`、`spawnTracer`、`spawnExplosion`（敵人與 M2 的元素特效沿用）。
- `Crosshair`（M1-14 組合進 HUD）。

## 驗收

- [ ] 貼牆時槍不穿模；改世界 FOV 不影響槍模大小。
- [ ] 以 1/60 與 1/240 的畫面速度錄影比較，viewmodel 動畫一致。
- [ ] 第一次開火不卡頓（frame time 圖）。
- [ ] 準星大小與實際彈著吻合：對牆連射 30 發，至少 90% 的彈孔落在準星圈內。
- [ ] 實機：5 把武器手感有明顯區別；附截圖。
