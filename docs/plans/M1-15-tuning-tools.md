# M1-15 調校工具：預設組合、錄製重播、示範、計時賽

- 里程碑：M1 手感原型
- 前置：M1-07、M1-14
- 狀態：未開始

## 目標

讓調手感變成可比較、可重現的工作：同一段操作改參數後重播比較，還能用計時賽量化流暢度。

## 範圍

- 包含：調參預設組合、輸入錄製與重播、鬼影路徑、`#demo` 示範、跑酷計時賽、傳送與慢動作。
- 不含：排行榜（M5-05）。

## 任務

- [ ] 調參預設組合：把 MovementConfig、鏡頭參數、各武器 `WeaponDef` 的目前值存成具名預設（`shardwake:presets:v1`）；可以載入、刪除、匯出 JSON（複製到剪貼簿或下載檔案）、匯入 JSON（貼上文字）；內建「標準」「高速」「穩重」三組供比較。
- [ ] 輸入錄製／重播（F8／F9）：錄下每個 fixed step 的 `InputFrame`，以及起始狀態（位置、速度、移動狀態、能力計時、亂數種子）；重播時從起始狀態重跑，結果必須確定一致；重播前可以改參數比較；錄影可以存成具名片段（localStorage 或匯出）。
- [ ] 鬼影對照：重播時同時畫出原始路徑與新路徑，並標示時間差。
- [ ] `#demo` 示範：用預設參數重播內建錄影（`src/debug/demo-clip.json`），自動展示「滑鏟 → 跑牆 → 蹬牆跳 → 二段跳 → Dash → 抓鉤」連招，供自動化驗證與截圖；預設參數改動導致路線失準時，重新錄製即可。
- [ ] 跑酷計時賽：起點門、依序通過的環形檢查點、終點；HUD 顯示計時與分段時間；最佳時間存在 `shardwake:besttimes:v1`；`restartCourse` 快捷鍵（預設 T）立即重來。
- [ ] 調參面板：傳送到各分區起點、慢動作 0.1×–1×。

## 交付（給後續計畫）

- 輸入錄製格式與確定性重播（之後的回歸測試與 bug 重現可以使用）。
- 計時賽成績（M5-05 可以接排行榜）。

## 驗收

- [ ] 測試：同一段錄影重播 3 次，最終位置誤差 < 1 mm。
- [ ] `#demo` 在平台模擬頁中自動完成連招，主控台無錯誤。
- [ ] 匯出的預設 JSON 再匯入後，數值完全一致。
