# M2-05 背包與物品介面 ★

- 里程碑：M2 刷寶核心
- 前置：M2-02、M2-03、M2-04
- 狀態：未開始
- 檢查點：★ 完成後可以試玩完整的「打靶 → 掉落 → 比較 → 裝備」循環

## 目標

讓整理裝備快速又清楚：一眼看出好壞，兩下完成比較與裝備。

## 設計

- 背包容量 60（之後可升級）；裝備欄：3 個武器欄，加上 M2-06 的護盾、推進器、抓鉤模組欄。
- 介面（Tab 開啟；單人遊戲，開啟時暫停時間）：分類頁籤、格狀清單與稀有度色框、排序（稀有度／等級／類型／取得時間）、篩選、物品詳細（數值條，加上與裝備中物品的 ± 比較）、鎖定、標記垃圾、分解（換晶核碎片）、一鍵分解所有垃圾。
- 比較：在物品卡上按住指定鍵，顯示詳細數值（DPS、對各防禦層的預估擊殺時間）。
- 武器欄對應 1–3 切槍；M1 的 1–5 測試欄改成訓練場的除錯功能。
- 開背包時解除 Pointer Lock，關閉後需要點擊才能重新鎖定（瀏覽器限制），介面要明確提示。
