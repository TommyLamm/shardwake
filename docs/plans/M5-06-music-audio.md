# M5-06 音樂與混音

- 里程碑：M5 成長、終局與上架
- 前置：M3-03（需要戰鬥強度 hook）
- 狀態：未開始

## 目標

用程序生成的合成器音樂撐起氣氛，讓音樂跟著戰鬥強度起伏；整體混音清楚、不吵。

## 設計

- 用 WebAudio 排程器即時演奏：每個生態區一組和弦進行與音色；錨點站與選單各有主題。
- 分層：探索、交戰、Boss 三層，依 M3-03 的戰鬥強度 hook 淡入淡出；Boss 換階段時變奏。
- 混音：爆炸與重要音效出現時，音樂側鏈避讓；音效有優先級；整體響度平衡。
- 設定新增音樂音量。

## 任務

- [ ] `audio/music/`：排程器、樂器（合成器音色）、樂曲資料格式。
- [ ] 各生態區、錨點站、選單、Boss 的樂曲。
- [ ] 強度分層與轉場。
- [ ] 混音調整與音量設定。

## 交付（給後續計畫）

- 音樂系統與樂曲格式（M5-04 的新生態區可以加樂曲）。

## 驗收

- [ ] 音樂循環沒有接縫；長時間播放時，音樂的 CPU 佔用 < 3%（Performance 量測）。
- [ ] 戰鬥開始與結束時，音樂轉場自然。
