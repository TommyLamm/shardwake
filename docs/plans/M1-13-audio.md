# M1-13 程序合成音效

- 里程碑：M1 手感原型
- 前置：M1-02（隨時可以做；事件整合要等 M1-07、M1-10 完成）
- 狀態：未開始

## 目標

不使用任何音效檔，用 WebAudio 合成所有聲音；每把武器、每個移動動作都有清楚、有份量、聽不出重複的聲音。

## 範圍

- 包含：音訊引擎、匯流排與音量、合成配方與預渲染、播放與隨機變化、空間音效、事件綁定。
- 不含：音樂（M5-06）。

## 任務

- [ ] `audio/AudioEngine.ts`：`AudioContext` 在玩家第一次點擊時建立或 resume（平台要求音效由玩家操作觸發）；匯流排 master → sfx／ui／music，master 前加壓縮器與限幅器防止爆音；音量設定 0–100% 存入設定。
- [ ] `audio/SynthRecipes.ts`：用參數描述音色（雜訊爆發＋帶通濾波、低頻正弦「砰」聲＋音高包絡、短殘響）；載入時用 `OfflineAudioContext` 預先渲染成 `AudioBuffer`，每種音效 3–5 個變體。
- [ ] 音效清單：
  - 武器：5 種開火（各自音色）、空倉、換彈（彈匣出／入、上膛）、切槍、開鏡、近戰揮擊、電漿飛行與爆炸。
  - 移動：腳步（依表面：金屬／格柵／玻璃）、跳躍、二段跳推進、噴射循環、落地（輕／重）、滑鏟摩擦循環、跑牆摩擦循環、蹬牆跳、攀爬、Dash 呼嘯、抓鉤發射／附著／收線循環、依速度變化的風聲。
  - 回饋：命中、爆頭（高音）、擊殺、護盾破裂、受擊、低生命心跳。
  - UI：懸停、點擊、確認、返回。
- [ ] 播放：每次音高 ±3%、音量 ±1 dB 隨機變化；同類音效有同時發聲上限；循環音依狀態事件開關，平滑淡入淡出。
- [ ] 空間音效：世界音源用 `PannerNode`（HRTF），listener 跟隨相機，遠距衰減。
- [ ] 事件綁定：訂閱 EventBus（`weaponFire`、`jump`、`land`、`dash`、`grapple*`、`hit` 等）後播放；各系統不直接呼叫音效。

## 交付（給後續計畫）

- `AudioEngine.play(id, opts)`、`loop(id)`、空間音源 API。
- 合成配方格式（M2 的元素、M3 的敵人音效沿用）。

## 驗收

- [ ] 音效預渲染總時間 < 1.5 s（記錄實測值），之後播放沒有延遲。
- [ ] 平台模擬頁中：點擊前不發聲，點擊後正常；切分頁回來後音效正常。
- [ ] 長時間連射不爆音、不卡頓；大量命中音同時播放時不失真。
