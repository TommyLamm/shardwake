# 碎晶航跡 SHARDWAKE — 設計總覽

## 一句話

在崩解的軌道巨構「晶格」碎片間高速穿梭，奪取原型武器的單人第一人稱科幻刷寶射擊遊戲。

## 設計支柱

1. **速度就是力量**：移動流暢、能自由串連，而且和戰鬥互相加成（機動系詞綴、疾行技能樹）。
2. **每次掉落都值得看**：詞綴有意義、比較清楚、稀有度一眼可辨。
3. **回饋清楚有力**：命中、爆頭、擊殺、受擊、掉落都有強烈且容易讀懂的視聽回饋。
4. **永遠有下一場**：程序生成任務、可分享的種子、難度階級與終局深潛。

## 世界觀（簡述）

七十年前，環繞氣態巨星運轉的運算巨構「晶格」在一夜之間崩解，數以萬計的碎片沿著軌道拖出一道發光的「碎晶航跡」。晶格的守護 AI「監序者」隨之分裂，殘存的「監序機群」仍在每塊碎片上執行早已失去意義的防衛協議，也守著晶格時代留下的原型武器。

你是拾荒公會的「疾行者」。穿上疾行外骨骼，從「錨點站」出發潛入碎片區，在碎片墜入巨星之前，把一切值錢的東西帶回來。

## 核心循環

錨點站整備 → 任務終端選擇（生態區、難度、修飾詞）→ 潛入碎片區（戰鬥、探索、拾取）→ Boss → 撤離與結算 → 整理裝備、升級技能、製作 → 挑戰更難的任務

## 美術方向

- 全部程序生成：幾何、Canvas 貼圖、粒子；不使用外部素材，也沒有授權問題。
- 色彩：深藍灰金屬基底；青色（主色）、洋紅（輔色）、橘色（警示）發光；Bloom 只作用在發光處。
- 速度感：地面與牆面保留清楚的格線與接縫，高速時才看得出移動。
- 稀有度色：普通 灰白、精良 綠、稀有 藍、史詩 紫、傳說 橙、原型 洋紅；另外加上形狀標記，讓色盲玩家也能分辨（M5-07）。
- UI：細線框、斜角、等寬數字、繁體中文。

## 音效方向

- 以 WebAudio 合成，載入時預先渲染。每把武器、每個移動動作都有專屬聲音，同一動作帶有細微隨機變化。
- 音樂是程序生成的合成器音樂，依生態區與戰鬥強度分層（M5-06）。

## 技術概要

- TypeScript、Vite、Three.js、Rapier（單執行緒 WASM）、pmndrs postprocessing、Tweakpane、Vitest。
- 固定 120 Hz 模擬加上畫面插值；滑鼠視角每個畫面直接套用。
- 遊戲邏輯與渲染分離（`InputFrame` → 模擬 → 事件 → 鏡頭／音效／特效／HUD），可以無頭測試，也能錄製重播。
- 效能目標：GTX 1650、1080p、高畫質 ≥ 120 FPS。
- 平台限制見 [PLAN.md 的「平台限制」](../PLAN.md#平台限制影響所有計畫)。
